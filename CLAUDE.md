# CLAUDE.md - Metronome Project Rules

## Project Overview
Online metronome application for jurigregg.com/metronome.

## Directory Structure
```
metronome-project/
├── .claude/
│   ├── commands/
│   │   ├── generate-prp.md   # /generate-prp command
│   │   └── execute-prp.md    # /execute-prp command
│   └── settings.local.json   # Claude Code permissions
├── CLAUDE.md           # This file - project rules
├── decisions.md        # Confirmed decisions (architecture, design, tech stack)
├── task.md             # Current task technical notes and gotchas
├── init/               # Init files (one at a time, numbered)
│   └── init-001-*.md   # Current feature request
├── prp/                # PRPs (Code generates from init, human reviews)
├── examples/           # Reference code examples
└── dist/               # Build output (deployable files)
```

## Key Files - ALWAYS READ THESE

1. **decisions.md** - All confirmed project decisions. Check before making assumptions.
2. **task.md** - Technical considerations and gotchas for current task. Critical implementation details here.
3. **init/init-###-*.md** - Current feature request to implement.

## Workflow

### For Claude Code:
1. Read `decisions.md` and `task.md` for context
2. Read current init file in `init/` directory
3. Generate PRP: `/generate-prp init/init-001-project-overview.md`
4. Human reviews generated PRP (with Claude.ai)
5. Execute approved PRP: `/execute-prp prp/prp-001-[name].md`
6. Output goes to `dist/` directory

### For Claude.ai:
1. Reference `decisions.md` and `task.md` when brainstorming
2. Create one init file at a time based on these files
3. Review PRPs generated by Code before approving execution

## Code Principles

- Single HTML file with embedded CSS/JS
- No build tools, no external dependencies
- Web Audio API for timing (see task.md for details)
- Accessible: focus states, ARIA labels, color contrast

## Deployment Target
- AWS S3 (dedicated bucket) + existing CloudFront distribution
- Path: jurigregg.com/metronome
